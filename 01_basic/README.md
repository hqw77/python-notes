# 基础语法 `01_basic/`

Python 语法地基，为后续阶段打基础。

| # | 文件 | 内容 | 案例 |
|---|---|---|---|
| 01 | 01_variables.py | 变量、基本类型、类型转换、is/== | `label` / `type` / `convert` / `multi` / `is_` |
| 02 | 02_strings.py | 字符串操作、格式化、编码 | 见文件 docstring |
| 03 | 03_condition.py | 条件判断、match/case、短路求值 | 见文件 docstring |
| 04 | 04_loop.py | for/while、break/continue、enumerate/zip | 见文件 docstring |
| 05 | 05_list_tuple.py | 列表、元组、切片、拆包 | 见文件 docstring |
| 06 | 06_dict_set.py | 字典、集合、哈希原理 | 见文件 docstring |
| 07 | 07_function.py | 参数类型、作用域、lambda、闭包 | 见文件 docstring |
| 08 | 08_file_io.py | 文件读写、CSV/JSON 基础 | 见文件 docstring |
| 09 | 09_comprehension.py | 推导式、生成器表达式 | 见文件 docstring |

## 运行方式

每个文件里的每个知识点封装成独立函数，支持跑全部或跑单个案例：

```bash
python 01_basic/01_variables.py           # 跑全部
python 01_basic/01_variables.py is_       # 只跑某个案例
```

可选案例名见各文件顶部 docstring 的【运行方式】。
